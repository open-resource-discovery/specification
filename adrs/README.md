Dependencies and related decisions are linked from each ADR's frontmatter. All records remain proposed until the pull request review resolves the open choices.
The ADRs explain design rationale; normative requirements are defined in the ORD specification and its interface definitions. In these records, **required v1 scope** is part of the standardized push API, an **optional v1 behavior** is already defined but not required, and a **future extension** is only a direction and is not yet standardized or interoperable.
