# Interfaces and Schemas

ORD defines a small set of complementary interfaces for discovering and exchanging metadata.
The human-readable reference pages explain their fields, while the JSON Schemas and OpenAPI definition provide machine-readable contracts for implementation and validation.

For pull transport, an ORD consumer first reads the [ORD Configuration](/spec-v1/interfaces/Configuration), which points to one or more [ORD Documents](/spec-v1/interfaces/Document) and describes how they can be retrieved.
ORD Documents carry the actual resource and taxonomy metadata.
[ORD Overlays](/spec-v1/interfaces/OrdOverlay) can optionally enrich supported metadata or referenced resource definitions without changing the original source files.
