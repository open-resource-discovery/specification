The ORD Aggregator Push API is a plain REST API that is described via an [OpenAPI 3.1 definition](https://spec.openapis.org/oas/v3.1.0).

The OpenAPI yaml file is published here: [/spec-v1/interfaces/AggregatorPushAPI.oas3.yaml](/spec-v1/interfaces/AggregatorPushAPI.oas3.yaml)

It can also be viewed via <a href="../ord-aggregator-push-api" target="_blank">Swagger UI</a>.
