## Tools and examples

- Browse the [example ORD files](../spec-v1/examples/index.mdx) or inspect a running provider in the [ORD Reference Application](https://ord-reference-application.cfapps.sap.hana.ondemand.com/).
- Use the [schema explorer](https://open-resource-discovery.org/tools/schema-viewer/index.html?schema=Document) and the [`@open-resource-discovery/specification`](https://www.npmjs.com/package/@open-resource-discovery/specification) package when implementing or validating documents.
- Read the [complete specification](../spec-v1/index.md) when you need normative requirements and detailed concept guidance.
- Watch the [introduction videos](./videos/index.mdx) or [ask the ORD NotebookLM](https://notebooklm.google.com/notebook/f57d6c36-a0b0-4baa-898b-efede2521382) for another way into the material.
- Report documentation or specification problems in the [GitHub repository](https://github.com/open-resource-discovery/specification/issues).
