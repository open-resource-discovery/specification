General Tool, Framework and Library Support​

The presentation's Tools & Ecosystem section provides a visual walkthrough of these projects and the tasks they support. Its source is available on GitHub.

Build and Publish​

  • Spec Toolkit generates JSON Schema specification documentation and related artifacts.
  • ORD Provider Server serves static ORD metadata from local files or a GitHub repository.
  • Spring Boot Starter for ORD adds annotation-generated or static ORD endpoints to Spring Boot applications.
  • ORD Maven publishes generated Java models and annotations for ORD.

Explore and Present​

  • The ORD Reference Application is a running Provider with public source code. Its embedded Explorer displays public or demo-authenticated tenant-specific metadata and native definitions.
  • ORD Explorer connects to an ORD Provider and lets users browse its catalog, relationships, and native resource definitions.
  • Metadata Renderer renders supported native metadata formats through one React API.
  • ORD UI Components provides the shared accessible and themeable React components used by the tool UIs.

Create and Apply ORD Overlays​

  • ORD Overlay Editor provides a browser playground and React components for viewing and editing overlays.
  • ORD Overlay Tools provides a TypeScript library and CLI for validating, dry-running, converting, and applying overlays.
  • ORD Overlay for Go applies overlays to supported native definition formats from Go.

AI and Agent Workflows​

ORD can describe and relate agent and protocol metadata. The following adjacent tools help developers inspect and test those native formats and interactions.

  • A2A Editor and the A2A Editor extension for VS Code support Agent Card editing, validation, and protocol testing.
  • A2A Sample Server provides test agents, while the ORD and A2A demo demonstrates ORD discovery followed by A2A communication.
  • MCP Server Card UI supports Server Card editing, validation, and MCP server testing.
  • The ORD MCP Server Card demo compares manual MCP setup with ORD-based discovery and static Server Card metadata.
  • Metadata Compactor for Go reduces metadata with configurable rules for more efficient use in LLM context.

Framework Support​

  • SAP ABAP Platform, including ABAP Cloud has inbuilt ORD support.
  • SAP CAP framework has an open source ORD plugin.
