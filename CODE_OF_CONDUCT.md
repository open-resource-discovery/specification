# Code of Conduct

Open Resource Discovery (ORD) is a NeoNephos Foundation project hosted by
Linux Foundation Europe. The project follows the
[LF Europe Code of Conduct](https://linuxfoundation.eu/policies/code-of-conduct),
which applies to all project participants and community spaces.

## Reporting

Report incidents or appeal incident reports confidentially to
[legal@linuxfoundation.eu](mailto:legal@linuxfoundation.eu), as prescribed by
the LF Europe incident procedure. Any project-specific confidential reporting
contacts appointed by ORD will be listed in [`Notices.md`](./Notices.md).

Do not submit Code of Conduct reports through public GitHub issues.
